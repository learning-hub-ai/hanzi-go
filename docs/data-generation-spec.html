1. Objective 目标

Generate structured JSON data files containing character-learning content extracted from the 统编版义务教育教科书·语文 (Nationally Standardized Chinese Language Textbooks), grades 1–9.

HARD RULES:
  • All data MUST be extracted verbatim from the textbook PDFs
  • No inference, no guessing, no creative additions
  • No external sources (internet, other textbook versions, encyclopedias)
  • All output MUST conform to the JSON Schema defined in Section 5
  • One output file per grade-semester combination

2. Scope 范围

✅ IN SCOPE (必须处理)

Content TypeGradesDescription
识字课 (Character Lessons)1–2Dedicated character-learning lessons
课文 (Texts/Readings)1–9Main lesson texts with associated characters
识字表 (Character Recognition Table)1–6Characters students must recognize
写字表 (Character Writing Table)1–6Characters students must write (subset of 识字表)
生字表 (New Character Table)7–9New characters per lesson for middle school

❌ OUT OF SCOPE (禁止处理)

  • 语文园地 / 快乐读书吧 (Reading Garden / Happy Reading)
  • 口语交际 (Oral Communication)
  • 拼音学习单元 (Pinyin Learning Units — Grade 1 only)
  • 课后练习 (Post-lesson exercises)
  • 插图说明 (Illustration captions)
  • 教师指导 (Teacher guidance notes)
  • 阅读链接 (Reading links)
  • 综合性学习 (Comprehensive learning activities)

5. JSON Schema 数据结构

Top-level Structure

{
  "grade": number,        // 1-9
  "semester": number,     // 1 (上册) or 2 (下册)
  "lessons": [Lesson]     // Array of lesson objects
}

Lesson Object

{
  "id": string,           // Format: "{grade}-{semester}-{sequence}"  e.g. "1-1-1"
  "title": string,        // Format: "{type}{number}《{title}》" e.g. "识字1《天地人》"
  "chars": [Character]    // Array of character objects
}

Character Object

{
  "char": string,         // Single Chinese character
  "pinyin": string,       // Pinyin with tone mark (e.g. "tiān")
  "words": [string],      // Array of words containing this character
  "sentence": string      // Original textbook sentence containing this character
}

Field Specifications

FieldTypeRequiredConstraints
gradeintegerREQUIRED1–9, must match filename
semesterintegerREQUIRED1 or 2, must match filename
lessonsarrayREQUIRED≥1 item, ordered by textbook sequence
idstringREQUIREDPattern: /^\d-\d-\d+$/
titlestringREQUIREDMust include 《》around lesson name
charstringREQUIREDExactly 1 Chinese character (length=1)
pinyinstringREQUIREDMust include tone mark (ā á ǎ à ē é ě è ī í ǐ ì ō ó ǒ ò ū ú ǔ ù ǖ ǘ ǚ ǜ). No numbered tones.
wordsarrayREQUIREDGrades 1–2: exactly 3 items. Grades 3–9: 2–3 items. No duplicates. Each word must contain the char.
sentencestringREQUIRED≤30 Chinese characters. Must contain the char. Must be verbatim from textbook.

6. Data Constraints 数据约束

6.1 Character (char) 生字

✅ MUST:
  • Come from the textbook's 识字表 (Grades 1–6) or 生字表 (Grades 7–9)
  • Be exactly 1 Chinese character
  • Be assigned to the correct lesson as listed in the character table
❌ MUST NOT:
  • Be invented or added by AI
  • Come only from the 写字表 without being in 识字表
  • Be a character from a different lesson

6.2 Pinyin (pinyin) 拼音

✅ MUST:
  • Use tone marks on vowels: tiān, rén, shuǐ
  • Match the textbook's indicated pronunciation for that lesson context
  • Use standard Hanyu Pinyin orthography
❌ MUST NOT:
  • Use numbered tones: tian1, ren2, shui3
  • Omit tone marks: tian, ren, shui
  • Use incorrect tone for the context (多音字 must match lesson usage)

6.3 Words (words) 词语

✅ MUST:
  • Grades 1–2: Provide exactly 3 words
  • Grades 3–9: Provide 2–3 words
  • Every word must contain the target char
  • All words must be different from each other
  • Words should be age-appropriate for the grade level
Word Source Priority:
  1. Words appearing in the lesson text (课文正文)
  2. Words from the textbook's 写字表 word column
  3. Common age-appropriate words from textbook vocabulary lists
❌ MUST NOT:
  • Include words inappropriate for the grade level (e.g., 工业/法律/互联网 for Grade 1)
  • Include duplicate words in the array
  • Include words that do NOT contain the target character
  • Exceed 3 words for grades 1–2 or go below 2 for any grade

6.4 Sentence (sentence) 句子

⚠️ THIS IS THE MOST CRITICAL FIELD — highest hallucination risk
✅ MUST satisfy ALL of:
  • Be an original sentence from the textbook (verbatim)
  • Contain the current char
  • Be ≤30 Chinese characters in length
  • Preserve original punctuation exactly
  • Come from the same lesson as the character
❌ MUST NOT:
  • Rewrite or paraphrase textbook sentences
  • Merge two sentences into one
  • Truncate in the middle of a phrase or clause
  • Modify punctuation
  • Invent sentences that "sound like" the textbook
  • Use sentences from a different lesson
Sentence Selection Priority:
  1. Short complete sentence from lesson text containing the character
  2. If all sentences > 30 chars: truncate at a natural clause boundary (at a comma 、or 。)
  3. If character does not appear in any lesson sentence ≤30 chars: use the shortest sentence containing it, truncated at clause boundary

7. Validation Rules 校验规则

Before outputting each character entry, the following checklist MUST pass. If ANY check fails, regenerate the entry.

#CheckFailure Action
1char is in the textbook's character table for this lessonRemove entry
2char is exactly 1 character (length = 1)Fix or reject
3pinyin contains a tone mark vowelAdd correct tone
4pinyin matches the character's pronunciation in this contextCorrect pinyin
5words array has exactly 3 items (grades 1–2) or 2–3 items (grades 3–9)Adjust count
6All items in words are unique (no duplicates)Replace duplicate
7Every word in words contains the target charReplace word
8sentence is from the textbook (verbatim)Find correct sentence
9sentence contains the target charFind different sentence
10sentence length ≤ 30 Chinese charactersTruncate at clause boundary
11JSON is syntactically validFix syntax
12Lesson id follows pattern {grade}-{semester}-{n}Fix ID
13Lesson title matches textbook lesson title exactlyCorrect title
File-level validation:
  • Total character count per file should match the textbook's character table count for that grade-semester
  • Lesson ordering must match textbook sequence
  • No duplicate characters within the same file
  • grade and semester values must match the filename

8. Hallucination Prevention 防止幻觉

🚨 ABSOLUTE PROHIBITIONS — AI MUST NOT:
  1. Invent words — Every word must be verifiable in the textbook
  2. Invent sentences — Every sentence must exist verbatim in the lesson text
  3. Guess textbook content — If content cannot be read from the PDF, output an error marker
  4. Mix textbook versions — Use ONLY the specific edition PDF provided
  5. Use internet examples — No external dictionaries, no Baidu, no example sentences from the web
  6. Create teaching examples — Do not generate "helpful" sentences that aren't in the book
  7. Modify textbook wording — No simplification, no modernization, no corrections
  8. Summarize textbook — Extract, do not summarize
  9. Rewrite for clarity — The textbook text is the truth, even if awkward
  10. Fill gaps with plausible content — When in doubt, use error recovery (Section 9)
Self-check trigger: Before writing any sentence value, ask: "Can I point to the exact page and line in the PDF where this sentence appears?" If the answer is no → use error recovery.

9. Error Recovery 错误恢复

When data cannot be confidently extracted from the source PDF:

Character-level error

{
  "char": "X",
  "pinyin": "",
  "words": [],
  "sentence": "",
  "_error": "Source data unavailable: [reason]"
}

Lesson-level error

{
  "id": "1-1-5",
  "title": "课文5《影子》",
  "chars": [],
  "_error": "Lesson content not readable from PDF"
}
When to use error recovery:
  • PDF text is garbled or unreadable for a section
  • Character table is unclear or pages are missing
  • Cannot find any sentence ≤30 chars containing the target character in the lesson
  • Pinyin is ambiguous (多音字) and context doesn't clarify
NEVER guess instead of using error recovery. An empty field with _error is infinitely better than hallucinated content.

10. Output Rules 输出规则

Output Format

✅ Output ONLY:
  • Valid JSON (UTF-8 encoded)
  • 2-space indentation
  • One file per grade-semester
❌ Do NOT include:
  • Markdown formatting or code fences
  • Explanatory text or commentary
  • Notes, warnings, or disclaimers
  • Comments (JSON does not support comments)
  • Trailing commas
  • BOM markers

File Naming

Output files must be named: grade{N}-semester{S}.json

Examples: grade1-semester1.json, grade9-semester2.json

12. Few-shot Examples 示例

✅ Correct Examples (Grade 1)

{
  "char": "天",
  "pinyin": "tiān",
  "words": ["天空", "今天", "蓝天"],
  "sentence": "天地人，你我他。"
}

Why correct: 3 words (grade 1), all contain 天, sentence is verbatim from 识字1《天地人》, ≤30 chars.

{
  "char": "水",
  "pinyin": "shuǐ",
  "words": ["水果", "河水", "水面"],
  "sentence": "一二三四五，金木水火土。"
}

Why correct: Pinyin has tone mark, sentence is verbatim from 识字2《金木水火土》.

✅ Correct Example (Grade 7)

{
  "char": "嗡",
  "pinyin": "wēng",
  "words": ["嗡嗡", "嗡鸣"],
  "sentence": "蜜蜂嗡嗡地闹着。"
}

Why correct: 2 words (grade 7), sentence from 课文1《春》by 朱自清, ≤30 chars.

❌ Incorrect Examples

{
  "char": "天",
  "pinyin": "tian",
  "words": ["天地", "天空", "天气"],
  "sentence": "天空真蓝。"
}

Errors:

  • ❌ pinyin: Missing tone mark (should be tiān)
  • ❌ sentence: "天空真蓝" does NOT appear in the textbook — hallucinated
{
  "char": "人",
  "pinyin": "rén",
  "words": ["人民", "人类"],
  "sentence": "我们都是中国人。"
}

Errors:

  • ❌ words: Only 2 words for Grade 1 (need exactly 3)
  • ❌ words: "人民"/"人类" inappropriate for Grade 1
  • ❌ sentence: Not from this lesson's text
{
  "char": "春",
  "pinyin": "chūn",
  "words": ["春天"],
  "sentence": "春天来了，万物复苏，到处充满了生机。"
}

Errors:

  • ❌ words: Only 1 word (need 2–3)
  • ❌ sentence: 35 characters — exceeds 30 char limit
  • ❌ sentence: Likely a rewrite, not verbatim from textbook

❌ Incorrect: Hallucinated Lesson Title

{
  "id": "1-1-1",
  "title": "识字1《日月水火》",
  ...
}

Error: 识字1 in Grade 1 Semester 1 is actually 《天地人》, not 《日月水火》. Title must match textbook exactly.

13. Grade-specific Rules 年级差异

AspectGrades 1–2Grades 3–6Grades 7–9
Character source识字表识字表生字表 / 课后注释
Lesson types识字 + 课文课文 only课文 only
Words per charExactly 32–32–3

Sentence sourceLesson text (often very short)Lesson text (longer prose)Lesson text (classical/modern literature)

Special Cases

多音字 (Polyphonic Characters):
  • Use the pronunciation indicated in the specific lesson context
  • If character appears with different readings in different lessons, use the lesson-specific reading
  • Example: 长 = cháng (long) or zhǎng (grow) — use whichever matches the lesson text
古诗/文言文 (Classical Chinese — Grades 3+):
  • Sentences from classical poems are acceptable as-is
  • Use the pinyin annotation provided in the textbook margin
  • Classical readings (e.g., 见=xiàn in 相见欢) should follow textbook notation
