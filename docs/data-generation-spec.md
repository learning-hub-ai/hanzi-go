**版本**: 1.0.0  
**日期**: 2026-07-30  
**适用范围**: 统编版义务教育教科书《语文》一年级至九年级（全18册）  
**输出格式**: JSON  
**编码**: UTF-8

## 一、目标

根据统编版义务教育教科书《语文》一年级至九年级（最新版），生成完整的识字/词语数据集，供 HanziGo 学习应用直接使用。

数据必须与教材保持 **100% 一致性**，保证准确性、统一性和可扩展性。

## 四、JSON 数据结构

### 4.1 顶层结构

```json
{
  "grade": <number>,
  "semester": <number>,
  "lessons": [<Lesson>, ...]
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `grade` | `number` | 年级编号（1–9） |
| `semester` | `number` | 学期编号（1=上册，2=下册） |
| `lessons` | `Lesson[]` | 课文数组，按教材顺序排列 |

### 4.2 Lesson 对象

```json
{
  "id": "<grade>-<semester>-<sequence>",
  "title": "<课文类型><序号>《<课文名称>》",
  "chars": [<CharEntry>, ...]
}
```

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `id` | `string` | 唯一标识符 `年级-学期-序号` | `"1-1-1"` |
| `title` | `string` | 课文完整标题 | `"识字1《天地人》"` |
| `chars` | `CharEntry[]` | 本课生字数组，按识字表顺序排列 |  |

#### title 格式规范

**小学（1–6年级）**:
- 识字课: `"识字<N>《<课名>》"`
- 课文: `"课文<N>《<课名>》"`
- 语文园地: `"语文园地<N>"`

**初中（7–9年级）**:
- 课文: `"第<N>课《<课名>》"`
- 综合性学习等按教材实际结构命名

### 4.3 CharEntry 对象

```json
{
  "char": "天",
  "pinyin": "tiān",
  "words": ["天空", "今天"],
  "sentence": "天在上，地在下。"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `char` | `string` | 单个汉字（识字表中的生字） |
| `pinyin` | `string` | 标准汉语拼音（带声调符号） |
| `words` | `string[]` | 包含该字的词语（2个） |
| `sentence` | `string` | 包含该字的课文原句 |

## 五、字段详细规范

### 5.1 `char` — 生字

**来源**: 教材识字表（小学）/ 课后生词表（初中）

**规则**:
- 每个字在全册中仅出现一次（不重复）
- 顺序严格按照教材识字表排列
- 仅收录教材明确要求"会认"的字
- 不收录写字表中不在识字表中的字

### 5.2 `pinyin` — 拼音

**来源**: 教材拼音标注

**规则**:
- 使用标准汉语拼音方案
- 必须带声调符号（ā á ǎ à）
- 轻声标注为无声调字母（如 `"de"`）
- 多音字采用该课文语境中的教材读音
- 儿化音按教材标注（如 `"huār"`）
- ü 在 l、n 后保留（如 `"lǜ"`、`"nǚ"`）
- ü 在 j、q、x、y 后写作 u（如 `"jū"`）

### 5.3 `words` — 词语

**来源优先级**:
1. 课文中出现的词语
2. 写字表/词语表中的词语
3. 教材配套常用词语

**规则**:
- 每个生字提供 **恰好2个** 词语
- 词语必须包含当前生字
- 词语长度：2–4字为宜
- 词语难度必须与年级认知水平匹配

**按年级词语难度参考**:

| 年级 | 词语要求 |
|------|----------|
| 1–2年级 | 常见日常词汇，口语化，贴近生活 |
| 3–4年级 | 可含书面语词汇，简单成语 |
| 5–6年级 | 可含较复杂词汇、常见成语 |
| 7–9年级 | 可含文学性词汇、文言词汇 |

**禁止**:
- ❌ 超纲词汇（超出该年级认知范围）
- ❌ 生僻词汇
- ❌ 网络流行语
- ❌ 含贬义或不雅的词语
- ❌ 专业术语

### 5.4 `sentence` — 例句

**来源**: 教材课文原文

**规则**:
- **必须** 来自本册教材课文原文
- **不允许** 自行改写或造句
- **必须** 包含当前生字
- 长度控制在 **30个汉字以内**
- 如原句较长，可截取完整分句（以标点断句），但不得修改原文文字
- 优先选取该字所在课文的句子
- 如本课无合适句子，可选同册其他课文中含该字的原句

**截取规则**:
- 可以按逗号（，）、分号（；）、句号（。）、感叹号（！）、问号（？）截断
- 截取后的句子必须语义完整
- 不得在句子中间截断

**初中（7–9年级）特殊说明**:
- 文言文课文中的句子可以使用，标注按原文
- 如生词表中的字在课文中仅出现在文言文中，优先使用现代文例句（如有）
- 若仅有文言文出处，则使用文言文原句

## 六、数据质量要求

### 6.1 必须满足

| 项目 | 要求 |
|------|------|
| 生字准确性 | 与教材识字表/生词表 100% 一致 |
| 拼音准确性 | 声调正确，多音字按教材语境 |
| 词语数量 | 每字恰好 2 个词语 |
| 词语来源 | 来自教材或符合年级水平的常用词 |
| 例句来源 | 100% 来自课文原文 |
| 例句长度 | ≤ 30 个汉字 |
| 字序正确 | 按教材识字表顺序 |
| JSON 合法 | 通过 `JSON.parse()` 无错误 |
| 编码规范 | UTF-8，无 BOM |
| 无重复 | 同一册内每字仅出现一次 |

### 6.2 禁止出现

- ❌ 其他教材版本内容
- ❌ 自行编写/改编句子
- ❌ 网络例句
- ❌ 同册内重复生字
- ❌ 重复课文条目
- ❌ 超纲词汇
- ❌ 生僻词汇
- ❌ 字段名称不统一
- ❌ 拼音缺失声调
- ❌ 非法 JSON 语法（尾逗号、注释等）

## 七、分年级特殊说明

### 7.1 一年级（Grade 1）

- 识字表为"会认"字，写字表为"会写"字
- 仅收录识字表中的字
- 拼音学习阶段的课文以识字为主，title 用 `"识字<N>《...》"`
- 汉语拼音单元中出现的字也按识字表收录
- 词语必须极其简单，贴近儿童生活

### 7.2 二年级（Grade 2）

- 延续小学识字表格式
- 课文开始有较完整的叙事文
- 词语可稍微扩展，但仍以口语化为主

### 7.3 三至六年级（Grade 3–6）

- 识字表字数逐步减少，但难度增加
- 课文体裁多样化（记叙文、说明文、古诗、寓言等）
- 古诗/文言文中的字，读音按教材注释标注
- 词语可含常见成语（4字）

### 7.4 七至九年级（Grade 7–9）

- 改为"生词表"形式（课后注音释义）
- 收录单位为"字"而非"词"（与小学保持一致的输出格式）
- 如教材生词表以"词"为单位，则拆分到单字级别
- 文言文课文中的通假字、古今异义字按教材注释处理
- 例句优先选择现代文，文言文为辅

## 八、生成流程

### 8.1 处理步骤（每册）

```
1. 打开对应 PDF 源文件
2. 定位识字表/生词表（通常在书末附录或各课后）
3. 按课文顺序逐课提取生字
4. 为每个生字确定拼音（从教材标注）
5. 为每个生字选取 2 个词语（按优先级规则）
6. 为每个生字在课文中定位包含该字的原句
7. 截取合适长度的句子（≤30字）
8. 组装 JSON 数据
9. 验证 JSON 格式合法性
10. 交叉检查：无重复字、字序正确、字段完整
```

### 8.2 验证清单

每个文件生成后，逐项检查：

- [ ] `grade` 和 `semester` 值正确
- [ ] 所有课文按教材顺序排列
- [ ] `id` 字段唯一且格式正确
- [ ] `title` 与教材一致
- [ ] 生字与识字表一致（无多无少）
- [ ] 生字无重复
- [ ] 拼音带声调且正确
- [ ] 每字恰好 2 个词语
- [ ] 词语包含当前生字
- [ ] 词语难度匹配年级
- [ ] 句子来自课文原文
- [ ] 句子包含当前生字
- [ ] 句子 ≤ 30 个汉字
- [ ] JSON 语法合法（可被 `JSON.parse()` 解析）
- [ ] 文件编码为 UTF-8
